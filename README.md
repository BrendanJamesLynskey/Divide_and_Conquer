# 🔀 Divide and Conquer — Presentation

An interactive slide deck covering the divide-and-conquer paradigm, recurrence relations, the Master Theorem, classic algorithms (merge sort, quick sort, binary search, Strassen's, FFT), and parallelism. Aimed at mid-level software engineers.
